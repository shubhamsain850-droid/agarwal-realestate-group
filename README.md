# Agarwal Real Estate Group (अग्रवाल रियल एस्टेट ग्रुप)

> **Bhankrota (PIN: 302026), Ajmer Road Corridor, Jaipur (Rajasthan)**  
> *भरोसा ज़मीन का, वादा तरक्की और पक्की रजिस्ट्री का।*

A tech-forward, hyper-local real estate portal designed for the fastest-growing property market in Western Jaipur. Built with modern React, TypeScript, Tailwind CSS, and featuring a built-in **AI Voice & Chat Property Consultant ("Pooja")** that handles customer inquiries in natural Hindi & English 24x7.

---

## 🌟 Key Features

### 1. Zero-Faltu, 100% Grounded Property Inventory
Every property listed is based on actual, legally vetted developments along the Ajmer Road corridor:
* **JDA Approved Residential Plots (200 ft Bhankrota-Jaisinghpura Link Road):** 111 & 200 Gaj plots, 40 ft bitumen roads, underground drainage, 80% SBI bank loan, immediate registry.
* **Luxury Duplex Villas (Near Delhi Public School, Ajmer Road):** 4 BHK gated community villas, Vastu-compliant, private rooftop terrace garden.
* **Highway Commercial SCO Plots (NH-48 & Ring Road Cloverleaf):** High footfall commercial plots for showrooms, offices, clinics.
* **Gated Weekend Eco-Farmhouses (Boraj - Begus Green Belt):** 600 Gaj mini-farmhouses with clubhouse, swimming pool, organic fruit orchard, and 24x7 security.
* **Industrial & Commercial Land Parcels (Ring Road Interchange):** 1.5 Bigha to 10 Bigha 90A-converted parcels for warehousing, logistics, and institutions.

### 2. Live AI Property Consultant ("Pooja")
* **Voice Call Mode:** Realistic voice call simulator with audio waveforms, speech synthesis in Hindi, active call timer, and live subtitle transcript.
* **Interactive Chat Mode:** Instant answers to common buyer queries in Hindi/English:
  * *"Bhankrota me plot rate kya hai?"*
  * *"SBI / HDFC se 80% bank loan mil jayega kya?"*
  * *"JDA patta aur registry clear hai?"*
  * *"Kal ke liye site visit schedule kar do."*

### 3. Interactive Housing Loan EMI Calculator
* Dynamic sliders for Loan Amount (₹5L to ₹1.5 Cr), Interest Rate, and Tenure (1 to 30 years).
* Instant calculation of monthly EMI, total interest, and total payment.

### 4. Colonizers, Builders & Land Owners Partner Desk
* Dedicated B2B desk for local colonizers and farmers to submit their plotted townships or land parcels for sales partnership with Agarwal Real Estate Group.

### 5. Instant WhatsApp & Free Site Visit Booking
* Pre-filled 1-click WhatsApp inquiry messages.
* On-site pickup booking form with Bhankrota / Mansarovar pickup assistance.

## 🛠️ Tech Stack

* **Framework:** React 19 + TypeScript
* **Build Tool:** Vite 8 + `@rolldown/binding-win32-x64-msvc`
* **Styling:** Tailwind CSS v4 (Emerald & Royal Gold luxury real estate palette)
* **Icons:** Lucide React
* **Speech Synthesis:** Web Speech API for voice interactions

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/shubhamsain850-droid/agarwal-realestate-group.git

# Navigate to project directory
cd agarwal-realestate-group

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
